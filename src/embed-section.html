Sept calendriers sur le site,
une seule balise.

Le site du parc embarque sept calendriers D-EDGE : les quatre nuits insolites, les deux gîtes Pyrénées Prestige et la vue d’ensemble de la page Hébergements. Chacun est refait ici dans la charte du prototype, avec les mêmes disponibilités et les mêmes limites de voyageurs qu’en ligne. Une balise HTML suffit pour l’installer sur n’importe quelle page.

Installation · une ligne dans la page
<script src="https://benitnoabenitez.github.io/parc-animalier-pyrenees/parc-calendrier.js" defer></script>
Attributs de la balise

logement : tous, taniere, refuge, trappeur, asian, grange ou moulin ; ou chambre="140910" avec l’identifiant D-EDGE. adultes, enfants, ages : composition de départ, que le visiteur modifie dans les limites fixées pour chaque logement sur le site. mois="2" : deux mois côte à côte. photo, titre, sous-titre : en-tête. design : cases, cercles ou lignes. theme="sombre" : fond bleu nuit, sélection dorée. compact : sans en-tête.

Ce que fait la balise

Elle interroge le même service public D-EDGE que les widgets du site, avec le jeton public déjà exposé sur les pages officielles. Elle affiche le tarif « dès » par nuit pour la composition choisie, dessine chaque nuit disponible du jour au lendemain, laisse déplacer le départ sur les nuits suivantes disponibles, revérifie la date, puis envoie vers le moteur officiel avec le logement, les dates, le séjour minimum et les voyageurs préremplis. Aucun paiement ni donnée personnelle ne transite par la balise. Un service qui ne répond pas n’est jamais affiché comme complet. Un événement parc-calendrier:selection est émis à chaque date choisie, pour la mesure d’audience si elle est autorisée.

Limites & mise en production

Le prototype dépend de la disponibilité du service D-EDGE, de son jeton public et de ses règles CORS : D-EDGE doit valider cette intégration avant un usage commercial. L’âge des enfants influence le tarif, la balise le demande comme le widget officiel. Les gîtes imposent un séjour minimum, affiché avec la date de départ correspondante. Le prix final et les conditions sont toujours confirmés sur le moteur officiel.
